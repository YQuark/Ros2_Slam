# 建图测试流程

## 前置门

在 SLAM 调参前必须完成：

- 固件参数 CRC、UART HIL 和当前上下位机提交锁定
- 轮径、有效轮距、轮方向和单轮最大周速确认
- wheel odom 直线/旋转/方形/8 字报告
- 雷达 yaw 标定和 scan 质量检查
- IMU 质量与 MCU→ROS 时间链检查
- `odom -> base_link` 唯一发布者检查

缺任一项时只允许采集诊断数据，不能把 SLAM 参数写成最终答案。

## 标准数据集

```text
bag_00_static
bag_01_straight
bag_02_rotation_cw
bag_03_rotation_ccw
bag_04_square
bag_05_figure8
bag_06_mapping_train
bag_07_mapping_validation
bag_08_navigation_validation
bag_09_fault_injection
```

至少记录 `/scan`、`/wheel/observation`、`/wheel/odom`、`/imu/data`、`/odom`、
`/tf`、候选命令、Host/Link/Firmware/Supervision/Compatibility 状态和 diagnostics，
并保存上下位机 commit、硬件 revision、参数 CRC、effective config/artifact hash 和
标定版本。

## wheel-only / wheel+IMU 对照

所有组使用相同 Bag 离线回放：

```text
A wheel-only
B wheel vx + wheel wz
C wheel vx + IMU gyro_z
D wheel vx + wheel wz + IMU gyro_z
```

比较静止漂移、直线终点、多圈旋转、方形/8 字闭环、创新残差、拒绝次数、TF 延迟和
CPU p95。只有独立验证 Bag 上 wheel+gyro 优于 wheel-only，且 IMU 停止可退回轮式
yaw、TF 仍唯一，才允许改变默认。

## SLAM 参数试验

按 `slam-sweep-v0.6.0-rc2.yaml` 在训练 Bag 做 seeded LHS 粗筛和交互复验；冻结候选
后只在验证 Bag 评分。任何缺指标、NaN、假回环或阈值超限均失败。不要同时修改
几何、雷达外参、融合模式和 SLAM 参数，否则无法归因。

## 现场最小观测

```bash
ros2 topic hz /scan
ros2 topic hz /wheel/odom
ros2 topic hz /odom
ros2 run tf2_ros tf2_echo odom base_link
./bin/robot check tf
./bin/robot check mapping --allow-headless
```

wheel+IMU 模式检查 `/odometry/filtered_internal`；wheel-only 没有该 topic 属于正常。
`/odom` 无论哪种模式都应来自 `formal_odometry`。
