# 运维与排障

## 入口与安全前提

运维入口为 `bin/robot`。真实底盘当前仍受 rc2 发布门阻塞；兼容门关闭、
`rearm_required`、ESTOP/fault、STATUS/ACK timeout 或 supervision critical 时，不得
通过直接 launch、改 topic 或 unsafe 参数绕过。

```bash
./bin/robot doctor
./bin/robot check lidar
./bin/robot check chassis
./bin/robot check tf
./bin/robot check mapping --allow-headless
./bin/robot check navigation
./bin/robot stop
```

## 分层排查

1. 供电、接线、急停和人员断电能力
2. `/dev/serial0`、`/dev/ydlidar` 是否存在、可读写且未被占用
3. `/scan` 和 provider Observation 是否新鲜
4. `chassis/link_state` 的 protocol/session/ACK/rearm
5. `platform/compatibility_state` 是否允许 formal odom/navigation
6. `/wheel/odom`、`/imu/data`、`/odom` 和 TF 是否按所有权发布
7. `motion/supervision_state` 和 Host control gate
8. AMCL 后再检查 Nav2 path/controller

## 底盘链路

```bash
ros2 topic echo /chassis/link_state --once
ros2 topic echo /chassis/firmware_control_state --once
ros2 topic echo /chassis/host_control_state --once
ros2 topic echo /platform/compatibility_state --once
ros2 topic echo /wheel/observation --once
```

- `DISCONNECTED/WAIT_HELLO`：先查串口、固件和 Upper v3。
- protocol/schema/capability 不兼容：不能回退 v2。
- ACK age/status age 无效：检查 session、UART 和固件 STATUS。
- Host 等待 quiet/fresh intent：停止旧来源至少一个 quiet window，再产生新意图。
- 固件 source 不是 Host：上位机 release 不能证明整车停止，以 STATUS 为准。

## Odom 与 TF

```bash
ros2 topic echo /wheel/odom --once
ros2 topic echo /odom --once
ros2 run tf2_ros tf2_echo odom base_link
```

`wheel/odom` 不更新时检查 STATUS sequence、session/reset、mask 和 anomaly；`wheel/odom`
正常而 `/odom` 不更新时检查 compatibility gate 和当前 session 新鲜证据。正式 `/odom`
及 TF 只应由 `formal_odometry` 发布。wheel+IMU 实验模式另查
`/odometry/filtered_internal` 和 IMU gyro 质量。

## 导航

有 `/plan` 但车不走时依次检查：

```bash
ros2 topic hz /cmd_vel/nav
ros2 topic echo /navigation/guard_state --once
ros2 topic echo /chassis/host_control_state --once
ros2 topic hz /chassis/host_motion_command
```

公共 Goal 由 `navigation_guard` 接收，后端是 `/nav2/navigate_to_pose`。故障撤权后必须
等旧 Goal 真正终止，再提交新 UUID；旧 Goal/Twist 不能复用。两阶段
`--localization-only`/`--nav2-only` 只用于诊断。

## 雷达

```bash
./bin/robot check lidar
ros2 topic hz /scan_raw
ros2 topic hz /scan
ros2 run tf2_ros tf2_echo base_link laser_frame
```

左右镜像先检查 `inverted/reversion`，再检查 yaw；不要修改 odom 符号掩盖雷达手性。
正式雷达配置来自 effective config，不是包内安装回退 YAML。

## 运行资源

```bash
vcgencmd measure_temp
vcgencmd get_throttled
```

记录 CPU p95、内存峰值、TF 延迟和 scan drop。故障注入与长稳必须写入
`verification/reports`，不能只保留终端截图。
