# 项目范围

> 当前基线：Platform API 5 + Upper protocol v3，发布候选
> `v0.6.0-rc2`。固件候选为 `bc472cc874e930aaed6eb8e7de73b41a2563dd85`，
> 但 UART HIL、参数 CRC、硬件版本和实车证据尚未记录，因此
> `release_compatible: false`。

## 项目定位

本项目为以激光 SLAM 为当前主链的移动机器人树莓派上位机工程。
目标是在原 x86 架构上位机仓库 `YQuark/Ros2_Slam` 的基础上，完成
面向树莓派 4B 的迁移、裁剪、重构和工程化适配。

仓库地址：[YQuark/Ros2_Slam](https://github.com/YQuark/Ros2_Slam)，当前工作分支为 `ARM`。

## 平台约束

| 项目 | 规格 |
|------|------|
| 上位机 | Raspberry Pi 4B 4GB |
| 操作系统 | Ubuntu 22.04 64-bit (arm64) |
| ROS2 版本 | Humble |
| CPU | 4×Cortex-A72 @ 1.5GHz |
| 内存 | 4GB LPDDR4 |
| 存储 | microSD |
| 散热 | 80°C 触发降频 |

当前配置基线为：SLAM Toolbox `stack_size_to_use=16000000`、
AMCL `max_particles=1000`、可选 EKF `frequency=30 Hz`、全局
costmap `update_frequency=2 Hz`。这些是针对 Raspberry Pi 4B 的工程初值，
不是已完成实车验收的性能结论。

## 当前硬件

| 设备 | 型号 | 接口 |
|------|------|------|
| 激光雷达 | YDLIDAR X2 | USB-UART (`/dev/ydlidar`) |
| 底盘控制板 | STM32F407 | Raspberry Pi GPIO UART (`/dev/serial0`) |
| IMU | BMI270 | 板载 SPI（STM32 侧） |
| 电机 | JGB37-520 × 2 | TB67H450FNG 驱动 |
| 编码器 | AB 相霍尔 × 2 | TIM 编码器模式 |

## 明确排除项

以下设备不属于当前硬件，相关代码路径已移除或禁用：

- **Astra Pro 深度摄像头**：属于后续 AI 扩展（Phase 7），当前激光 SLAM 主链路不包含摄像头
- **四轮差速 / 麦轮底盘**：旧 x86 工程遗留，当前为两轮差速
- **ESP01S 通信**：预留路径（USART2），不参与 ROS2 主链路

## 核心任务

1. 接入 YDLIDAR X2，发布可靠 `/scan`
2. 接入 STM32 upper v3，发布 `wheel/observation`、`imu/observation` 和底盘状态；状态估计生成 `wheel/odom`、`imu/data`，融合层独占 `/odom` 与 `odom -> base_link`
3. 支持 SLAM Toolbox 手动建图；自主探索属于 legacy 实验，不是当前平台模式
4. 支持 Nav2 定位导航（AMCL + DWB Planner）
5. 支持手动遥控和键盘控制
6. 后续接入摄像头实现 AI 检测识别（非 rc2 范围）

## 与下位机的同步约定

本工程与下位机工程 [Yaoser-x/SlamRobot_Chassis_Control](https://github.com/Yaoser-x/SlamRobot_Chassis_Control) 同步推进。以下内容以下位机代码为权威来源：

- 串口帧格式、命令字、校验算法
- 数据字段顺序、类型、缩放系数
- 控制模式枚举、错误位定义
- 固件编码器尺度与方向定义；上位机标定值以
  `src/robot_config/config/calibration/` 为唯一事实源
- IMU 坐标系、电压电流换算参数

这些跨仓事实只有在 `compatibility/firmware.yaml` 中写入已测 commit、
参数 CRC 和硬件版本，且 UART HIL 报告 PASS 后，才能称为发布兼容。
