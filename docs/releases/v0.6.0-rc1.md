# v0.6.0-rc1 发布候选

该候选将 ROS Platform API 升级到 5，Upper v3 线协议保持不变。它冻结 Host 候选与整车物理职权边界，并引入会话绑定兼容门、跨机 rearm、布局感知里程计、独立 Twist 协方差、公开 Navigation Guard Action 代理、统一 Chassis Operation，以及语义 Fake/PTY 两级替身。

发布仍为 fail-closed：UART HIL、标定、导航和长时间运行报告目前为 `NOT_RUN`，不得把软件测试通过解释为实车发布通过。升级必须同时携带上位机 commit、下位机 commit、Platform API 5、Upper v3、标定包、配置 SHA 和黄金向量 SHA；回滚时整组回滚，不允许混用 API 4 消息。
