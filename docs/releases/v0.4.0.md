# v0.4.0 发布候选

v0.4.0 将 Platform API 和 upper wire protocol 升级为 v3，采用会话 ACK、BridgeCore、编码器增量里程计、字段级 IMU 质量、MotionSupervisor 与编译后的单一配置。

当前状态为 **BLOCKED**：已知 beta4 固件仅支持 v2；v3 下位机 commit、HIL、实车、底盘动态和 final 标定均不存在。不得把模板或静态测试解释为硬件通过。

升级：刷入兼容矩阵中未来锁定的 v3 firmware，运行 `bin/robot` 生成有效配置，完成 `verification` 下所有机器报告，再执行 `python3 scripts/verify/verify_release.py`。回滚必须整体回滚到上位机 v0.3.0 + beta4/v2，禁止 v2/v3 混搭。
