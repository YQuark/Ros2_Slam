# v0.4.0 迁移与兼容

正式入口从 `launch_scripts/robot.sh` 迁移为 `bin/robot`。旧入口在 v0.4.x 自动转发，计划在 v0.5.0 删除。真实底盘直接调用 launch 且没有 effective params 会 fail-closed。

配置从 `robot_common.yaml`、`robot_calibration.yaml` 和 launch 覆写迁移到 `src/robot_config/config`；每次运行产物保存在 robot data runs 目录并包含 SHA-256。旧 YAML 只保留指向规范位置的迁移标记。

Platform API 2 / upper v2 升级到 v3 后不提供 runtime fallback。`v1.0.0-beta4@a4ae10d5` 被明确列为不兼容。回滚必须整体回滚上位机 v0.3.0 和 beta4/v2，禁止跨版本混搭。

实验、HIL 和报告规范入口迁移到 `verification/`；`config/experiments`、`tools/experiments` 与 `reports/experiments` 的旧入口只保留一个版本周期。
