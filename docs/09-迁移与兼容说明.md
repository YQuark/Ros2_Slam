# 迁移与兼容说明

当前主线为 Platform API 5 + Upper Protocol v3。Platform API 3/4、
`chassis/command`、裸 `/cmd_vel/driver`、Bridge odom/TF 和 Upper v2 都是历史接口，
不得与 rc2 运行图混用。

运维入口迁移到 `bin/robot`；`launch_scripts/robot.sh` 只保留兼容实现，不拥有配置
编译。真实/Fake Base 必须使用 `src/robot_config/config` 编译出的 effective params。
旧 `robot_common.yaml`、`robot_calibration.yaml`、包内 SLAM/Nav2 YAML 是安装兼容或
开发回退，不是正式事实源。

固件 `v1.0.0-beta4@a4ae10d5` 明确不兼容。当前候选
`v1.0.0-rc1@bc472cc` 只有 candidate 身份；HIL 后才允许同时填写 tested、compatible、
参数 CRC 和硬件 revision。回滚必须整体回滚到一组已验证的上下位机版本，不能只回滚
ROS 消息或 wire 一侧。

旧 `config/`、`reports/`、`launch_scripts/` 入口在 v0.6.x 只读兼容；新实验、数据集、
HIL 和报告统一进入 `verification/`。历史 release 文档不决定当前兼容状态。
