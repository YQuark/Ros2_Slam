# 系统架构（兼容入口）

当前权威说明为 [系统架构](./architecture/system-overview.md)、[配置事实源](./architecture/configuration.md) 和 [TF 所有权](./architecture/tf-ownership.md)。

v0.4.0 主链为：

```text
Twist sources -> robot_control -> ChassisCommand(session/sequence)
-> BridgeCore -> upper v3 -> STM32

encoder count -> wheel/odom --+
IMU gyro ------> imu/data -----+-> robot_localization -> odom + odom->base_link TF
```

包内 topic 默认使用相对名称，并由 launch namespace 组合。`robot_control` 是 `chassis/command` 唯一发布者；bridge 不发布 TF。真实底盘必须从 `bin/robot` 启动，以保证 effective config 已编译并记录 hash。
