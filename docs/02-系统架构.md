# 系统架构

本仓库是 Raspberry Pi 4B 上的 ROS 2 Humble 平台工作区。重构后的边界原则是：

- `src/` 只放 ROS package。
- 第三方源码通过 `deps/*.repos` 拉取到 Git 忽略目录。
- `robot_bringup` 只组合平台包，不实现设备、串口、状态估计或控制仲裁。
- 科研仓库只接稳定 ROS 接口，不直接访问串口、YDLIDAR SDK 或底层 bridge。

## 包职责

| 包 | 负责 | 不负责 |
| --- | --- | --- |
| `robot_description` | `base_link`、`base_footprint`、`laser_frame`、`imu_link` 等静态 TF | 雷达驱动、里程计 |
| `robot_sensing` | YDLIDAR ROS2 driver 启动，`/scan_raw -> /scan` 标准化 | SLAM、Nav2 |
| `stm32_robot_bridge` | STM32 串口、v2 帧解析、底盘原始状态、`/wheel/odom` | `/odom` 所有权、控制仲裁 |
| `robot_state_estimation` | wheel `vx` + IMU `gyro_z` EKF、`/odom` 与 `odom -> base_link` | 串口协议 |
| `robot_control` | `/cmd_vel/*` 候选命令仲裁、限速、超时释放、发布 `/chassis/command` | 串口协议 |
| `robot_bringup` | 组合 mapping/navigation profile | 设备实现、科研算法 |

## 数据链路

```text
YDLIDAR X2
  -> ydlidar_ros2_driver_node
  -> /scan_raw
  -> scan_normalizer
  -> /scan
  -> slam_toolbox / Nav2
```

```text
STM32 bridge
  -> /wheel/odom
  -> robot_state_estimation
  -> /odom + odom -> base_link
```

当前固件 v2 通过 `IMU_STATUS(0x83)` 单独上报 IMU 数据，`stm32_robot_bridge` 发布为 `/imu/data`；本仓库不发布伪造 IMU 数据。实车默认启用 EKF，初始策略只融合 wheel `vx` 与 IMU `gyro_z`，不融合无磁力计约束的绝对 yaw 或线加速度。

## 控制链路

```text
/cmd_vel/teleop
/cmd_vel/nav
/cmd_vel/test
/cmd_vel/research/<name>   # 必须在 robot_control 配置中白名单登记
        |
        v
robot_control
        |
        v
/chassis/command
        |
        v
stm32_robot_bridge -> STM32
```

规则：

- `stm32_robot_bridge` 默认只订阅 `/chassis/command`。
- `robot_control` 是唯一应发布 `/chassis/command` 的平台包。
- Nav2 通过 launch remap 输出到 `/cmd_vel/nav`。
- 手动遥控输出到 `/cmd_vel/teleop`。
- 底盘测试输出到 `/cmd_vel/test`。

## 依赖边界

| 类型 | 管理方式 | Git 跟踪 |
| --- | --- | --- |
| 自研 ROS 包 | 正常提交 | 是 |
| ROS Humble 官方包 | apt + rosdep | 否 |
| `robot_localization` | `ros-humble-robot-localization` | 否 |
| YDLIDAR ROS2 driver | `deps/ydlidar-ros2-driver.repos` 拉到 `src/vendor/` | 否 |
| YDLIDAR SDK | `deps/ydlidar-sdk.repos` 拉到 `vendor/` 后安装到 `/opt/slamrobot/vendor/ydlidar-sdk` | 否 |
| 第三方补丁 | `deps/patches/` | 是 |
| 地图、bag、日志、实车标定 | `/home/robot/robot_data`、`/home/robot/.config/slamrobot` | 否 |

## 默认启动

`robot.sh` 默认 headless：

```bash
./launch_scripts/robot.sh mapping lidar --manual --real-base --no-rviz
./launch_scripts/robot.sh navigation --real-base --map /home/robot/robot_data/maps/latest.yaml --no-rviz
```

需要可视化时显式追加 `--rviz`。
