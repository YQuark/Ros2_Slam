# 底盘与串口桥接

v0.4.0 只安装 v3 bridge 运行时。线协议见 [Upper protocol v3](./interfaces/upper-protocol-v3.md)，状态、安全和模块边界见 [系统架构](./architecture/system-overview.md)。beta4/v2 仅保留黄金测试 fixture，不能与本版本运行。

操作入口：

```bash
./bin/robot base
./bin/robot base-test --rotate-only
./bin/robot check chassis
```

bridge 在 HELLO 身份与能力、STATUS 新鲜度和当前 session ACK 全部满足前保持 fail-closed。命令或 STATUS 超时、ESTOP/fault、firmware reject、MotionSupervisor critical 都会发送 release 并要求 disable→enable 重新使能。原始里程计使用四轮累计 encoder count；轮速只用于 twist、异常与 slip 估计。

当前兼容 firmware commit 为空，所以上述真实底盘命令预期不能进入 READY；这是发布阻塞，不是允许退回 v2 的理由。
